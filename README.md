# Adaptive Interface Revamp

첨부한 1~2 이미지는 모바일 로그인 전후의 디자인, 첨부한 3~4 이미지는 데스크탑 로그인 전후의 디자인이다. 

첨부한 html의 화면에서 첫화면만 첨부한 이미지 1~4처럼 리뉴얼 한것이다. 첨부한 디자인 그대로 적응형(모바일,데스크탑 레이아웃이 다른 형태) 형태로 구현해줘. 나머지 화면은 html화면 기반으로 디자인 톤앤매너 유지해서 만들어줘
